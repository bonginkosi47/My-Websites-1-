## Project Overview
This project is an official website developed for Azania Izwe Lokudla, an organization dedicated to promoting community food security, sustainable agriculture, and indigenous culinary heritage (Azania Izwe Lokudla, 2026)[cite: 1]. The site acts as a digital portal for sharing organizational mission details, showcasing products and services, accepting volunteer/sponsor submissions, and facilitating direct communication[cite: 1].

---

## Website Goals and Objectives
* Educate visitors about Azania Izwe Lokudla’s mission, agricultural initiatives, and community impact (Azania Izwe Lokudla, 2026)[cite: 1].
* Showcase organic farm products, agricultural services, and market days[cite: 1].
* Provide a clear process for potential volunteers and sponsors to register via interactive enquiry forms[cite: 1].
* Deliver a fully responsive, accessible experience across desktop, tablet, and mobile platforms following responsive layout guidelines (MDN Web Docs, 2026)[cite: 1].

---

## Key Features and Functionality
* **Consistent Navigation:** Site-wide navigation menu ensuring fluid transitions across all 5 main pages[cite: 1].
* **Responsive Styling:** Custom CSS layout utilizing CSS Grid and Flexbox for screen adaptation (W3Schools, 2026)[cite: 1].
* **Interactive Forms:** Specialized validation-ready forms on `enquiry.html` and `contact.html`[cite: 1].
* **Accessible Visual Hierarchy:** Structured typography using relative units (`rem`, `em`) and accessible color contrast standards (MDN Web Docs, 2026)[cite: 1].

---

## Sitemap
1. **Home (`index.html`)** - Primary hero banner, organization overview, and direct calls to action[cite: 1].
2. **About Us (`about.html`)** - History, core principles, mission statements, and team profiles (Azania Izwe Lokudla, 2026)[cite: 1].
3. **Services/Products (`services.html`)** - Product listings, sustainable farming initiatives, and community outreach programs[cite: 1].
4. **Enquiry (`enquiry.html`)** - Dedicated enquiry form for service requests, volunteer sign-ups, and sponsorship proposals[cite: 1].
5. **Contact Us (`contact.html`)** - Location maps, operating hours, and standard contact messaging form[cite: 1].

---

## Part 2 Implementation Details
* **External Stylesheet:** Linked via `css/style.css` across all 5 HTML documents[cite: 1].
* **Typography & Styling:** Styled with system sans-serif typography (`Aptos`), an earth-inspired color palette, and relative spacing units (`rem`, `em`) to maintain consistent proportional scaling (MDN Web Docs, 2026)[cite: 1].
* **Responsive Media Queries:** Implemented CSS `@media` rule breakpoints targeting desktop (>1024px), tablet (768px - 1023px), and mobile (<767px) viewports (W3Schools, 2026)[cite: 1].
* **Layout Adaptability:** Converted multi-column grid layouts into single-column vertical stacks on mobile displays to optimize readability and user navigation (MDN Web Docs, 2026)[cite: 1].
