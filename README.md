## Project Description
Azania Izwe Lokudla is a responsive 5-page web application designed for a township food brand in Orange Farm, Gauteng. The website showcases menu items, company story, catering enquiries, interactive Google Maps location, and contact options.

---

## Technical Features Implemented
1. **Semantic HTML5 & CSS Layouts:** Clean semantic structure with flexbox, CSS Grid, and custom color variables.
2. **Client-Side Form Validation:** Dynamic JavaScript validation on `contact.html` and `enquiry.html` for inputs, emails, phone numbers, and text lengths.
3. **Interactive Search Filtering:** Real-time search filter on `services.html` for quick menu navigation.
4. **Interactive Google Maps Embed:** Embedded Google Maps location on `contact.html`.
5. **Technical SEO:** Structured meta description tags, `robots.txt`, and `sitemap.xml`.
